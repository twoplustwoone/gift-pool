The Radix Icons sprite the app ships (`other/svg-icons`, built into `app/components/ui/icons/sprite.svg`, used as `<Icon name="check" />`). 15×15 fill icons in `currentColor`: seen here as an `<img>` they render black, but in use they take the surrounding text token (`foreground`, `muted-foreground`, `success`, `destructive`). Lucide (via `react-icons/lu`) is the main icon set and isn't copied here.
