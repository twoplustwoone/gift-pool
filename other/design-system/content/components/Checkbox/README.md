# Checkbox

A 16px Radix checkbox: a terracotta outline that fills when checked.

**Props:** the Radix Checkbox root props: `checked`, `defaultChecked`, `onCheckedChange`, `disabled`, `id`, `name`.

- Always give it a `Label` with a matching `htmlFor`.
- For an instant on/off setting, use Switch instead.

Source: `app/components/ui/checkbox.tsx` in twoplustwoone/gift-pool, bundled as is.
