# Switch

The one toggle: a `role="switch"` button with a 44px hit area around a 40×24 track.

**Props:** `checked` and `onCheckedChange` (controlled, both required), `label` (a visually hidden name) or `aria-labelledby`, `aria-describedby`, `disabled`, `id`.

- Use for settings that apply immediately, like notification channels.
- Render the visible text yourself and name the switch with `label` or `aria-labelledby`.

Source: `app/components/ui/switch.tsx` in twoplustwoone/gift-pool, bundled as is.
