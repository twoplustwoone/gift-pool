# Badge

A compact pill for counts and small categories.

**Props:** `variant` (`default`: `muted` fill with `muted-foreground` text; `pool`: solid `pool` with `pool-badge-foreground`), plus span attributes. Children are the label.

- Keep labels to a word or two: "3 ideas", "Pool".
- For a pool's lifecycle, use PoolStatusBadge, not a Badge.

Source: `app/components/ui/badge.tsx` in twoplustwoone/gift-pool, bundled as is.
