# EmptyState

A quiet bordered block for a list with nothing in it yet, offering one next step.

**Props:** `title` (required), `description`, `action` (usually one `sm` Button).

- Offer one purposeful activation step. Don't advertise unrelated features.
- No-results and "all caught up" states stay smaller and quieter than first-run states.

Source: `app/components/ui/empty-state.tsx` in twoplustwoone/gift-pool, bundled as is.
