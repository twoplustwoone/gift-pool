# SystemLabel

A tiny muted pill for annotations the system adds (you, owner, from wishlist), so they never read as part of a name.

**Props:** `children` (one short word) and `className`.

- Place it right after the name it annotates.
- Role badges with icons are a different component. This is for lightweight inline markers only.

Source: `app/components/ui/system-label.tsx` in twoplustwoone/gift-pool, bundled as is.
