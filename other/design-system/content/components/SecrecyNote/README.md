# SecrecyNote

A dashed teal callout that states a privacy boundary: what this viewer can't see, and why.

**Props:** `title` (also its accessible name, default "What stays private") and `children` (the explanation).

- Use it wherever a page hides something on purpose: the pool recipient boundary, an organizer's totals-only view, a non-participant's roster.
- It's a deliberate line, not an error. Never style it red or amber.
- Say who it's hidden from by name when you can: "Hidden from Maya".

Source: `app/components/ui/secrecy-note.tsx` in twoplustwoone/gift-pool, bundled as is.
